# Vagas de Referência para Comparação ATS (Senior Data Engineer)

## Vaga 1: Senior Data Engineer (Fintech / E-commerce - Ex: Mercado Livre / Nubank)
**Descrição da Vaga:**
Buscamos um Engenheiro de Dados Sênior para projetar, construir e escalar nossa arquitetura de dados em nuvem. O candidato trabalhará em estreita colaboração com cientistas de dados e engenheiros de software para processar volumes massivos de dados em tempo real e batch.
**Requisitos Obrigatórios:**
- Experiência avançada com PySpark, Apache Spark Tuning (Broadcast Joins, Partition Pruning) e Delta Lake.
- Domínio de orquestração de pipelines com Apache Airflow.
- Experiência sólida com dbt (data build tool) e modelagem dimensional (Star Schema / Kimball).
- Conhecimento de Cloud (AWS ou GCP) e bancos de dados relacionais/NoSQL.
- Inglês intermediário a avançado.

---

## Vaga 2: Analytics Engineer Sênior (Marketplace - Ex: QuintoAndar / iFood)
**Descrição da Vaga:**
Procuramos um Analytics Engineer para liderar a transformação de dados analíticos, garantindo confiabilidade, governança e alta performance nas tabelas Gold e modelos de negócio.
**Requisitos Obrigatórios:**
- Domínio absoluto de SQL avançado, dbt e Databricks.
- Experiência com arquitetura Lakehouse e governança de dados (LGPD, linhagem, data quality).
- Forte capacidade de comunicação para trabalhar com equipes de produto e negócio.
- Conhecimento de Git, CI/CD e testes automatizados (PyTest / dbt test).

---

## Vaga 3: Senior Data Platform Engineer (Remoto Internacional)
**Descrição da Vaga:**
We are looking for a Senior Data Engineer to scale our global data platform. You will be responsible for building robust ingestion pipelines, data warehousing in Snowflake/BigQuery, and infrastructure automation.
**Requirements:**
- 5+ years of experience in Data Engineering.
- Deep expertise in Python, SQL, and Spark.
- Experience with Terraform / IaC and cloud data warehouses (Snowflake / BigQuery).
- Fluent or advanced English is mandatory.
- Experience with real-time streaming (Kafka / Flink) is a strong plus.
